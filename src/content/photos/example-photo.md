## How to Add Photos

Via admin dashboard (recommended):
1. Visit `/admin/`
2. Click "Photos" → "New Photo"
3. Fill in title, description
4. Upload your image
5. Select category
6. Click "Publish"

Via markdown files:
1. Copy this file
2. Update the frontmatter with your photo details
3. Add image to `/public/images/photos/`
4. Commit and push to GitHub

## Photo Categories

- **All** - Shows every photo
- **Street** - Street photography
- **Nature** - Landscapes, plants, animals
- **People** - Portraits and people
- **Places** - Specific locations

The category field determines where your photo appears when filtered.
