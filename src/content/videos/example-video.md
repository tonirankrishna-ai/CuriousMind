## How to Add Videos

Via admin dashboard (recommended):
1. Visit `/admin/`
2. Click "Videos" → "New Video"
3. Enter the YouTube watch, share, or embed URL, or paste the video ID
4. Add title and description
5. Set duration (e.g., "12 min")
6. Choose category
7. Click "Publish"

Via markdown files:
1. Copy this file
2. Update frontmatter with your details
3. Use a YouTube URL or its 11-character video ID
4. Commit and push to GitHub
