# Type Specimen Poster

A deep dive into typography through a printed poster design.

## How to Add Projects

Via admin dashboard (recommended):
1. Visit `/admin/`
2. Click "Projects" → "New Project"
3. Fill in all details
4. Add tags (comma-separated)
5. Set status: completed/ongoing/planned
6. Optionally add GitHub and demo links
7. Click "Publish"

Via markdown files:
1. Copy this file
2. Update frontmatter
3. Add project image to `/public/images/projects/`
4. Commit and push

## Project Fields

- **Title**: Project name
- **Description**: What you built
- **Tags**: Technology/type of work (e.g., web-design, branding, 3d)
- **Status**: completed/ongoing/planned
- **GitHub**: Link to source code (optional)
- **Demo**: Link to live demo (optional)
- **Featured**: Show on homepage (true/false)

## Status Examples

- **Completed**: Finished and shipped
- **Ongoing**: Still working on it
- **Planned**: Want to build but haven't started
